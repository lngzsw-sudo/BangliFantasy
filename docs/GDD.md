# Game Design Document (GDD) - High Level Concept
**Project Name (Working Title):** Bang Li Fantasy / บางลี่แลนด์  
**Platform:** Web Browser (Mobile & Desktop Responsive, Zero-Install)  
**Genre:** 2D Pixel Art Social Sandbox MMORPG & Casual Arcade  
**Target Engine/Tech Consideration:** Phaser.js / Pixi.js + Canvas / Colyseus (WebSocket) / Node.js Backend

---

## 1. Core Vision & Pillars (เสาหลักของเกม)
เกม 2D Pixel Art มุมมอง Top-down บนเว็บเบราว์เซอร์ ที่จำลองบรรยากาศและสีสันของ "ตลาดบางลี่" ในเชิงล้อเลียน (Parody) ปนน่ารัก โดยเน้นความง่ายในการเข้าถึง (Accessibility) ไม่ผูกมัดเนื้อเรื่องแบบเส้นตรง (Free Play) ผู้เล่นล็อกอินเข้ามาพบปะกันได้ทันที และมีระบบรองรับทั้งสายสังสรรค์ สายแต่งตัว และสายฟาร์มเลเวล

1. **Instant Social & Free Play:** ล็อกอินแล้วเกิดใจกลางตลาดทันที ไม่มีคัตซีนหรือติวเตอร์เรียลบังคับ พิมพ์แชตมี Bubble ลอยบนหัว และอวดชุดแฟชั่นได้ทันที
2. **Classic Point-and-Click + Auto-Farm:** ระบบต่อสู้แบบ "จิ้มตี" สไตล์คลาสสิก คำนวณสเตตัสบนเซิร์ฟเวอร์ เปิดแท็บบอทฟาร์มทิ้งไว้ข้างจอได้
3. **Close-up Overlay Mini-Games:** สลับฉากเป็นมุมมองระยะประชิด (Close-up) เพื่อเล่นมินิเกมกระดานหรืออาร์เคด โดยที่ตัวละครยังปล่อยบอทฟาร์มอยู่เบื้องหลังได้
4. **Grind-to-Drip Economy:** ลูปเศรษฐกิจแบบ "ฟาร์มมาแต่งตัว" ของดรอปจากมอนสเตอร์คราฟต์เป็นชุดแฟชั่นและยานพาหนะสุดกวน

## 2. World & Map Architecture (ระบบแผนที่แบบ Room-Based)
แผนที่สร้างขึ้นแบบ **แบ่งเป็นห้อง/โซน (Room-by-Room)** เชื่อมต่อด้วย **จุดวาร์ป/ประตูพอร์ทัล (Portal Points)** เพื่อลดการกิน RAM ในเบราว์เซอร์ และช่วยให้เซิร์ฟเวอร์กระจายโหลดผู้เล่น (Room ID) ได้ง่าย

### โครงสร้างห้องหลัก:
* **[Room 01] ลานกลางตลาดสดบางลี่ (Central Market - Safe Zone / Spawn Point)**
  * พื้นที่ปลอดภัย ห้ามต่อสู้ จุดศูนย์รวมผู้เล่นใหม่และเก่า
  * จุดนั่งแชตริมทาง, ร้านกาแฟโบราณ, ร้านตัดเสื้อ (คราฟต์แฟชั่น)
  * กระดานรับงานชุมชน (Daily Bounty Board) สำหรับรับเควสต์ล่ามอนสเตอร์
* **[Room 02] ซอยแคบหลังตลาด (Level 1–15)**
  * แผนที่แคบ ทางเดินปูน มีสิ่งกีดขวาง (ลังโฟม, รถเข็น)
  * มอนสเตอร์: หนูท่อลมปราณ, ฝูงนกพิราบแย่งข้าว, หมาจรจัดประจำซอย
  * เหมาะกับการเปิดบอทระยะสั้น มอนสเตอร์เกิดไว วิ่งวนไม่หลุดโซน
* **[Room 03] ชุมชนริมคลองสองพี่น้อง & ท่าเรือ (Level 15–35)**
  * แผนที่แนวยาวเลียบสะพานไม้และริมน้ำ
  * มอนสเตอร์: ผักตบชวากลายพันธุ์ (สกิลสโลว์), กิ้งก่ายักษ์พรางตัว (โจมตีติดพิษ)
  * มินิบอส: เรือหางยาวซิ่งน้ำบาน (สร้างคลื่นสึนามิขนาดเล็ก)
* **[Room 04] ชานเมือง & โกดังร้าง (Level 35–50+)**
  * แผนที่เปิดกว้าง มอนสเตอร์ตีแรง ดรอปวัตถุดิบทำแฟชั่นขั้นสูง
  * มอนสเตอร์: หุ่นไล่กาสเต็ปเทพ, ฝูงแตนแตกรัง, ควายเหล็กคลั่ง
  * เวิลด์บอส: รถพ่วงข้างแต่งซิ่งติดลำโพงงานวัด (ต้องรวมปาร์ตี้ตีตามเวลา)
* **[Room 05] ซุ้มงานวัด & หน้าศาลเจ้า (Event & Minigame Zone)**
  * แผนที่พักผ่อน แสงสีนีออน ไม่มีมอนสเตอร์
  * ตู้สอยดาว/กาชาปองโบราณ, เซียมซีดิจิทัลสุ่มบัฟประจำวัน, เวทีประชันท่าเต้น Emote

## 3. Core Gameplay Loops (ระบบการเล่นหลัก)

### 3.1 Combat & Auto-Farm System (ระบบต่อสู้และบอท)
* **การควบคุม:** คลิก/แตะที่พื้นเพื่อเดิน, คลิกที่มอนสเตอร์เพื่อล็อกเป้าหมาย ตัวละครเดินเข้าหาระยะอาวุธและเริ่มผลัดกันแลกดาเมจตามค่า ASPD (Attack Speed)
* **โหมด Auto-Play:** 
  * ปุ่มสลับเปิด-ปิดบอท
  * สแกนเป้าหมายที่ใกล้ที่สุดในห้องอัตโนมัติ
  * กินยาฟื้นพลังอัตโนมัติตาม % เลือดที่กำหนด
  * รองรับการเปิดแท็บเบราว์เซอร์ทิ้งไว้ (Idle Tab)
* **ประเภทอาวุธพื้นฐาน:** ไม้กวาดทางมะพร้าว (กวาดดาเมจหมู่), ตะหลิวเหล็ก (คริติคอล), ร่มแม่ค้า (บล็อกดาเมจ)

### 3.2 Close-up Mini-Game Layer (มินิเกมซ้อนหน้าจอ)
* เมื่อเดินไปมีปฏิสัมพันธ์กับ Object เฉพาะ เช่น โต๊ะหน้าร้านกาแฟ หรือแผงผลไม้ หน้าจอจะเปิด Overlay Popup ขึ้นมาเป็นภาพ **Close-up รายละเอียดสูง**:
  * **เกมกระดานดวล 1v1:** หมากฮอสไทย, การ์ดจับคู่ (เห็นมุมมองก้มมองโต๊ะ)
  * **เกมอาร์เคดแคชชวล:** เกมเรียงกล่องสินค้า, เกมสแกนของตามบิลให้ทันเวลา
* **เบื้องหลัง:** ตัวละครยังสามารถรัน Auto-farm ในแผนที่ไปพร้อมกันได้โดยเกมไม่สะดุด

### 3.3 Social, Chat & Fashion Hub
* **Real-time Bubble Chat:** พิมพ์ข้อความแล้วเด้งขึ้นเหนือหัวแบบการ์ตูน พร้อมระบบ Emotes ท่าทาง (ยกมือไหว้, นั่งยอง, ท่าแว้น)
* **ระบบแฟชั่นแยกชิ้นส่วน:** หมวก/ทรงผม, เสื้อผ้า (ชุดวินมอเตอร์ไซค์, ชุดชาวบ้าน, สตรีทแวร์), พร็อพถือ (ถุงโอเลี้ยง, พัดลม, ตะกร้าหวาย), สัตว์เลี้ยง/ยานพาหนะ
* **ตู้โชว์และความสำเร็จ:** ยิ่งเลเวลสูงหรือสะสมของจากเควสต์ได้เยอะ ยิ่งปลดล็อกชุดที่แปลกตามาใส่เดินอวดใน Safe Zone

## 4. Technical Specifications & Developer Handoff Notes

* **Client Architecture:**
  * Render Engine: HTML5 Canvas ผ่าน WebGL (เช่น Phaser.js หรือ PixiJS) สำหรับกราฟิก 2D Pixel Art
  * UI Framework: HTML/CSS (React, Svelte หรือ Vanilla) ซ้อนทับ Canvas เพื่อทำหน้าต่าง Chat, Inventory, และ Close-up Popup ให้ตอบสนองต่อจอมือถือได้ง่าย
  * Input Handling: รองรับ Touch Events และ Mouse Click (Tap to Move / Tap to Attack)
* **Networking & Synchronization:**
  * ใช้ **WebSocket (State Sync via Rooms)**: ผู้เล่นส่งคำสั่ง `move_to(x,y)` หรือ `attack(target_id)`
  * เซิร์ฟเวอร์ทำหน้าที่เป็น Authoritative Server ในการคำนวณดาเมจ, Drop Rate, และการขยับของมอนสเตอร์ตาม Tick Rate (5–10 ticks/s สำหรับ Classic MMO เบาๆ)
  * แยกลอจิกห้องตาม `Room ID` เมื่อเดินแตะจุด Portal จะทำการ `leave_room()` และ `join_room()` ใหม่
* **Data Storage:**
  * User State / Inventory / Equipment เก็บลง Database (เช่น Supabase / PostgreSQL / SQLite)
  * Session Cache ชั่วคราวบนเซิร์ฟเวอร์สำหรับตำแหน่งผู้เล่นในห้อง (Redis / In-Memory State)

## 5. Scope for Minimum Viable Product (MVP)
1. **Milestone 1:** ตัวละคร 2D เดินบน Tilemap ได้ มี 2 ห้องเชื่อมต่อกันด้วยจุด Portal วาร์ปข้ามไป-มาได้
2. **Milestone 2:** ห้องที่ 1 เป็น Safe Zone รองรับ WebSocket พิมพ์แชตลอยบนหัวได้พร้อมกันหลายคน
3. **Milestone 3:** ห้องที่ 2 มีมอนสเตอร์ 1 ชนิด (หนูท่อ) คลิกจิ้มตีแล้วตัวเลขดาเมจขึ้น มอนสเตอร์ดรอปเหรียญและเศษขยะ
4. **Milestone 4:** เพิ่มปุ่ม Auto-farm ให้ตัวละครวิ่งตีหนูท่อเองในห้องที่ 2
5. **Milestone 5:** ทำหน้าต่าง Close-up Popup มินิเกมง่ายๆ 1 เกม และร้านค้าเปลี่ยนชุดแฟชั่น 1 ชุด
